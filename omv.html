OpenMediaVault: Manual de Ingeniería NAS

Guía integral para la gestión de servicios en red y almacenamiento persistente.

Caso Práctico: "Estudio Pixel Flow"

Necesitamos configurar una carpeta compartida central llamada "PROYECTOS". El reto es gestionar tres tipos de perfiles distintos para que la información esté organizada y segura.

Escenario

Un administrador total, un editor con permisos de trabajo y un cliente que solo puede revisar el material.

Meta Técnica

Implementar permisos ACL y visibilidad SMB bajo una estructura jerárquica clara.

1. Conceptos Fundamentales (A Fondo)

Montaje (Mountpoint)

En los sistemas Linux, el hardware no es accesible directamente por el usuario. El "montaje" es el proceso de asignar una partición de un disco duro a un directorio específico del árbol de archivos. Sin este paso, el sistema operativo no puede escribir ni leer en el disco físico.

Protocolo SMB / CIFS

Es el estándar de comunicación que permite a equipos Windows "hablar" con servidores Linux. Funciona en la capa de aplicación y se encarga de que las carpetas remotas aparezcan como locales en el Explorador de Archivos.

Wipe y Particionado

El "Wipe" elimina la tabla de particiones (MBR/GPT). Esto es crucial para que OpenMediaVault pueda crear un sistema de archivos limpio (normalmente EXT4) sin que existan conflictos con datos o formatos antiguos.

Permisos y ACL

Las Listas de Control de Acceso (ACL) permiten definir reglas granulares. Mientras que los permisos estándar de Linux son básicos, las ACL nos permiten decir exactamente: "Este usuario lee, este escribe y este otro no puede ni entrar".

2. Preparación de la Práctica (Checklist)

  • Máquina Virtual OMV encendida y en modo Adaptador Puente.
  • Segundo disco virtual (mínimo 10GB) conectado a la VM.
  • Credenciales de Root (Consola) y Admin (Web) a mano.
  • Conexión IP establecida entre Anfitrión y Máquina Virtual.

3. Comandos de Consola: Uso y Función

Diagnóstico de Red
ip a

Función:

Muestra la dirección IP local del servidor. Es imprescindible para saber dónde apuntar el navegador para la configuración web.

Estructura de Discos
lsblk

Función:

"List Block Devices". Te permite ver todos los discos y particiones. Se usa para verificar que el sistema ha detectado el disco de 10GB que añadimos.

Monitorización de Espacio
df -h

Función:

"Disk Free" en formato legible (human). Sirve para confirmar que un disco está montado y ver el espacio real disponible.

4. Perfiles de Usuario (Configuración)

Admon

Rol: Super Administrador

  • Pass: a1234
  • Acceso: Total (Gestión + Archivos)
  • Grupos: sudo, ssh, users

user1

Rol: Usuario Operativo

  • Pass: u1234
  • Acceso: Lectura / Escritura
  • Grupos: users

guest

Rol: Invitado

  • Pass: guest
  • Acceso: Solo Lectura
  • Grupos: users

Nota Técnica: Gestión de Identidades

¿Debo crearlos en Debian? No. Los usuarios deben crearse exclusivamente a través de la interfaz web de OMV (Usuarios > Usuarios). OMV actúa como un orquestador que crea automáticamente la cuenta en la terminal de Debian y sincroniza las contraseñas con el servicio de red Samba.

5. Pasos en la Interfaz Web (GUI)

  1. 1

    Preparar el Almacenamiento:

    Ve a Almacenamiento > Discos. Selecciona el disco de 10GB y realiza un Wipe. Luego en Sistemas de Archivos, créalo (EXT4) y móntalo.

  2. 2

    Alta de Usuarios:

    En Usuarios > Usuarios, pulsa el botón + y crea a Admon, user1 y guest con sus respectivas contraseñas.

  3. 3

    Compartir Carpetas:

    En Servicios > SMB/CIFS > Shares, añade "PROYECTOS". Entra en la pestaña de Permisos de la carpeta para asignar a cada usuario su nivel de acceso correspondiente.

IMPORTANTE: No olvides pulsar el botón amarillo de Aplicar cambios en la barra superior tras cada configuración.

Comandos de Emergencia (CLI)

Reiniciar servicios si la web falla
omv-salt deploy run nginx
omv-salt deploy run samba
Reiniciar red si pierdes conexión
systemctl restart networking
